# 🏠 Медиакоми — Симулятор оценки недвижимости

Интерактивный веб-симулятор, который позволяет пользователю угадывать цену на квартиры по фото и описанию.

## 🎮 Механика

- Для каждого раунда берётся 10 случайных объявлений из базы данных
- Пользователь видит фото квартиры, описание и адрес
- Двигает бегунок, чтобы назвать свою цену
- Нажимает "Оценить" и видит правильный ответ
- Система подсчитывает баллы в зависимости от точности

### Система баллов

| Отклонение от реальной цены | Баллы |
|---|---|
| До 5% | 100 |
| 5-10% | 80 |
| 10-20% | 60 |
| 20-30% | 40 |
| 30-50% | 20 |
| Больше 50% | 0 |

### Итоговые результаты

- **🏆 Опытный инвестор** (700+ баллов) — близок к результату
- **💸 Щедрый инвестор** — переплачивает за недвижимость
- **🤑 Скряга** — экономный инвестор

## 🛠 Технологии

- React 18 + TypeScript
- Vite
- Tailwind CSS v4
- Без тяжёлых библиотек

## 🚀 Запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build

# Предпросмотр продакшен-сборки
npm run preview
```
